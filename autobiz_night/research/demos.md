# Демо-проекты для портфолио гигов

Условия: Windows, i5 6-го поколения, 8 ГБ RAM, без видеокарты, без платных API. Каждое демо делается за 2–4 часа: Claude пишет код и данные, Олег запускает, проверяет и снимает скриншоты.
Где публиковать: в Portfolio гига (картинки, PDF) и в публичный GitHub-репозиторий `oleg-fiverr-demos`. Ссылку на GitHub ставить только в профиль или портфолио, не в переписку (см. fiverr-rules.md §5).
Все данные в демо — **синтетические** (генерирует скрипт), чтобы не было вопросов о правах.

## Гиг 1 — Google Sheets / Excel
**Демо 1.1 «Sales report on autopilot» (≈3 ч)**
- Google Sheet: вкладка `Raw` (500 строк синтетических продаж) → вкладка `Report` на QUERY, XLOOKUP, SUMIFS → дашборд с 2 графиками.
- Apps Script: меню «Report → Refresh» + триггер раз в день, который пишет итоги в лист `Log` (без отправки почты, чтобы ничего не уходило наружу).
- Результат: ссылка «view only» + 3 скриншота «до/после» + GIF с работой кнопки (ScreenToGif, бесплатно).
**Демо 1.2 «Inventory template» (≈2 ч)**
- Excel-шаблон склада: приход/расход, остатки, подсветка низких остатков, выпадающие списки. Без VBA, работает в LibreOffice и Excel.

## Гиг 2 — Чистка и конвертация данных
**Демо 2.1 «Messy CRM export → clean» (≈3 ч)**
- `make_messy.py` генерирует CSV на 20 000 строк с типичным мусором: дубли с разным регистром, даты в 4 форматах, пробелы, телефоны в разных форматах, пустые строки.
- `clean.py` (pandas) → `clean.xlsx` + `quality_report.md`: «rows in / out, duplicates removed, invalid emails, normalized dates».
- Скриншот «до/после» и сам отчёт как PDF — это главный аргумент гига.
**Демо 2.2 «PDF table → Excel» (≈2 ч)**
- Сгенерировать текстовый PDF со счётом или прайсом (reportlab), извлечь таблицу (pdfplumber), сравнить суммы. Показать «✔ totals match».

## Гиг 3 — Python-автоматизация (инженерная)
**Демо 3.1 «Sensor log analyzer» (≈3–4 ч)**
- Вход: CSV или серийный лог (синтетический: температура, ток, вибрация с шумом и выбросами).
- Скрипт: фильтрация, поиск выбросов, статистика, графики matplotlib → PDF-отчёт одной командой `analyze.py logs/`.
- Упаковка в .exe через PyInstaller (на i5 сборка занимает ≈5 мин).
- Связь с реальным опытом: проект PaintMixer в этом репозитории (serial + Python) можно упомянуть как [ПОРТФОЛИО ОЛЕГА], если Олег согласен его показывать.
**Демо 3.2 «Batch file organizer» (≈2 ч)**
- Сортировка и переименование 1 000 файлов по дате/типу/шаблону, dry-run режим, лог. Простой GUI на Tkinter.

## Гиг 4 — Технический перевод и оформление
**Демо 4.1 «Datasheet EN→RU» (≈2–3 ч)**
- Взять **открытый** документ с разрешающей лицензией (например, README или доку open-source железа под CC-BY/MIT) на 1–2 страницы. Перевести и сверстать в DOCX и PDF (pandoc или LibreOffice) с глоссарием терминов. Указать источник и лицензию.
**Демо 4.2 «Game UI localization» (≈2 ч)**
- CSV-таблица строк интерфейса Godot (`keys,en,ru`) на ~80 строк с плейсхолдерами `{player}`, `%d`. Скрипт проверяет, что плейсхолдеры сохранены. Демо подходит и для идей из itch.md.

## Порядок (если времени мало)
1.1 → 2.1 → 3.1 → 4.2. Четыре демо примерно за 11–13 часов работы Claude, Олегу на проверку и скриншоты уходит ≈1,5–2 ч.
