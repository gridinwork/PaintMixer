# itch.io: инструменты и код для Godot (без 3D)

Факты по площадке:
- Выплаты через PayPal или Payoneer. Продавец сам выбирает долю itch.io (по умолчанию 10%, можно от 0 до 100%). Для «itch.io Payouts» нужна налоговая анкета (W-8BEN для не-США). Комиссия процессора ~2,9% + $0,30 — ПРОВЕРЕНО: [itch.io/docs/creators/payments](https://itch.io/docs/creators/payments).
- Есть отдельный раздел инструментов с тегом godot и платные плагины: Node2D Gizmo от $10, Item Drops Plugin $20, Sprite Animation Builder $4,99 — ПРОВЕРЕНО: [itch.io/tools tag-godot](https://itch.io/tools/made-with-godot/store/tag-godot), [Node2D Gizmo](https://skyebee.itch.io/editor-node2d-gizmo-plugin/purchase).
- Продажи конкретных инструментов не публикуются. **ДОПУЩЕНИЕ:** у нового автора без аудитории обычно 0–5 продаж в первый месяц. Бесплатный Godot Asset Library забирает часть спроса. Поэтому itch — **долгий канал** (пассивный доход и портфолио), а не деньги за неделю.

Шкала та же: С — спрос, К — слабая конкуренция, Б — скорость первой продажи, Ц — цена, М — масштабируемость.

## Идея 1 — «Localization Toolkit for Godot 4» (CSV ↔ PO, проверка плейсхолдеров)
- Плагин для редактора: импорт и экспорт таблиц перевода, подсветка недостающих ключей, проверка `{var}` и `%s`, отчёт о покрытии языков. Плюс Python-скрипт для CI.
- Цена $5–8. Пересекается с гигом 4 (локализация) — двойная польза.
- С2 К2 Б1 Ц1 М3 = **9**

## Идея 2 — «2D Dialogue & Quest Data Kit» (JSON/CSV → Resources)
- Импорт диалогов и квестов из Google Sheets или CSV в Resource-файлы Godot, простой рантайм-проигрыватель диалогов, пример сцены.
- Конкуренция есть (Dialogic и др. бесплатные), поэтому нишевой упор — «таблица → игра без кода», связь со Sheets. Это пересекается с гигом 1.
- С2 К1 Б1 Ц2 М3 = **9**

## Идея 3 — «Sprite Sheet & Animation Importer CLI + plugin»
- Python-CLI: нарезка спрайтшитов, упаковка атласов, автогенерация SpriteFrames и AnimationPlayer по именам файлов. Плагин запускает CLI из редактора.
- Прямой конкурент Sprite Animation Builder ($4,99), но можно сделать pay-what-you-want с минимумом $3.
- С3 К1 Б1 Ц1 М3 = **9**
