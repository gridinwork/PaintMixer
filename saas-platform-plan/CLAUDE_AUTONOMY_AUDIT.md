## 2. 15 вопросов

| # | Вопрос | Ответ | Кат. |
|---|---|---|---|
| 1 | Автогенерация sitemap.xml | Да, на этапе сборки сайта (из списка страниц). Строка `Sitemap:` в robots.txt. | A |
| 2 | Отправка sitemap в Google | Да, через Search Console API (`sitemaps.submit`) — нужно один раз подтвердить домен (DNS TXT) и добавить сервисный аккаунт как пользователя свойства. Отправка = «сообщить о карте», **не гарантия индексации**. | B |
| 3 | Проверка статуса индексации | Да, URL Inspection API. Документированная квота: 2 000 запросов/день и 600/мин на сайт ✔ ([док. лимитов](https://developers.google.com/webmaster-tools/limits)); перепроверить актуальные цифры. | B |
| 4 | Заставить Google проиндексировать страницу | **Нет.** Indexing API официально только для JobPosting и BroadcastEvent ✔ ([док.](https://developers.google.com/search/apis/indexing-api/v3/using-api)); обход запрещён. Кнопка «Запросить индексирование» в интерфейсе — ручная и с лимитом. Лучшие законные средства: sitemap, внутренние ссылки, качественный уникальный контент, внешние упоминания. | C |
| 5 | Поисковые запросы из Search Console | Да, Search Analytics API (запросы, страницы, клики, показы, средняя позиция). Данные с задержкой ~2–3 дня; редкие запросы анонимизируются. | B |
| 6 | IndexNow | Да. Один раз разместить файл-ключ на сайте; дальше пинги при публикации. Поддерживают Bing, Yandex, Naver, Seznam, Yep; **Google не поддерживает** ✔ (обзор 2026, [SEO-источники](https://rightblogger.com/blog/indexnow-bing-indexing); официальную страницу открыть не удалось). | B |
| 7 | Проверка позиций | Средняя позиция — из Search Console (законно, бесплатно). Парсинг выдачи Google нарушает его условия и ненадёжен → **не делаем**. | B / D (парсинг) |
| 8 | Исправление технических SEO-ошибок | Да — в нашем репозитории: битые ссылки, мета-теги, canonical, hreflang, schema, скорость. Я предлагаю PR/коммит, деплой — по CI после вашего утверждения. Ошибки у стороннего хостинга я не исправлю. | A (код) / C (деплой) |
| 9 | Ежедневная статистика | Да: cron на сервере/GitHub Actions тянет GSC, Bing, собственную аналитику в БД и формирует отчёт. | B |
| 10 | Публикация видео через официальные API | Технически YouTube Data API есть, но проекты без аудита, созданные после 28.07.2020, загружают видео только как **private** ✔ ([док. videos.insert](https://developers.google.cn/youtube/v3/docs/videos/insert)); стоимость загрузки в квотах противоречиво описана (100 vs 1600) — проверять в консоли. Практично: я готовлю сценарий, субтитры, описание; владелец загружает вручную. | C |
| 11 | Размещение в каталогах | Формы + модерация + CAPTCHA; автоотправка нарушает правила многих каталогов. Я готовлю тексты, скриншоты, чек-лист; владелец отправляет 5–10 качественных каталогов вручную. Сервисы «отправить в 300 каталогов» — исключить. | C / D |
| 12 | Ручная модерация обязательна | Product Hunt, Hacker News (нет API публикации Show HN, вручную), подфорумы Reddit (правила и модераторы), каталоги ПО, Google Play / Microsoft Store (ревью), Chrome Web Store. | — |
| 13 | Нужны дополнительные разрешения | Доступ к Search Console (DNS TXT + сервисный аккаунт), Bing Webmaster (API-ключ), Cloudflare (API-токен ограниченных прав), GitHub (токен/App), Paddle или другой платёжный провайдер (API-ключ), YouTube OAuth (при необходимости), DEV.to/Hashnode API-ключи. | B |
| 14 | Бесплатные инструменты | Search Console, Bing Webmaster, IndexNow, Cloudflare (DNS, CDN, Pages, Web Analytics), GitHub + Actions (в рамках бесплатного лимита), PageSpeed Insights API, Lighthouse CI, Google Trends, Umami/Plausible (self-host), Screaming Frog free (до 500 URL) ⚠. | — |
| 15 | Работа без запущенного Claude Code | Все регулярные задачи = обычные скрипты (Python) + `systemd timer`/cron на вашем сервере или GitHub Actions по расписанию. Они детерминированы и пишут журнал. «Интеллектуальные» шаги (выбор тем, анализ) — либо правила/шаблоны, либо локальная LLM на вашем GPU, либо ручной запуск сессии Claude раз в неделю по готовому отчёту. Платные вызовы API Anthropic из cron — это **расходы**, поэтому по умолчанию не закладываются. | B |

## 3. Что Claude НЕ делает без вашего решения
Создание аккаунтов, оплата, публикации на внешних площадках, отправка писем, изменения DNS. Все публикации проходят очередь утверждения (`approvals`).

## 4. Однократные действия владельца (сводка)
1. Купить домен; подключить Cloudflare (DNS).
2. Создать Search Console свойство (DNS TXT) и Bing Webmaster (импорт из GSC).
3. Создать Google Cloud проект + сервисный аккаунт; добавить его в Search Console.
4. Зарегистрировать платёжного провайдера и пройти верификацию (см. MONETIZATION_PLAN).
5. Создать токены: Cloudflare, GitHub, DEV.to/Hashnode (по желанию).
6. Сервер/VPS или домашний ПК с туннелем.
