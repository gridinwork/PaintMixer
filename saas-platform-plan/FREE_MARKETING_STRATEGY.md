# FREE_MARKETING_STRATEGY.md — Бесплатное продвижение

Дата: 2026-10-12. Бюджет рекламы: $0. ✔ проверено · ⚠ общие знания (перепроверить правила площадки перед публикацией) · ❓ гипотеза.

## 0. Главный принцип
Ставка на **один основной канал — органический поиск (Google + Bing)**, плюс **два-три разовых запуска вручную**. Любая площадка, которую нельзя поддерживать честно и автоматизируемо, исключена. Позиции в Google **не гарантируются**; новые домены обычно проходят период низкого доверия в несколько месяцев ⚠ (на AdSense тоже: см. отчёты о «low value content» для новых сайтов ✔ [DEV](https://dev.to/bdubs/i-applied-for-adsense-and-got-rejected-for-low-value-content-hog) — анекдотически).

## 2. Что войдёт в стратегию (после критического аудита)

**Рекомендуется (ядро):**
1. SEO-страницы инструментов (по одной уникальной странице на инструмент + руководства + FAQ + schema).
2. Search Console + Bing + IndexNow + автоматические отчёты.
3. Страницы «перевод PDF» с реальными демонстрациями (до/после), 10–20 языковых пар.
4. Один запуск Product Hunt + один Show HN (только если есть содержательная история, например «PDF-инструменты, где файл не покидает ваш браузер»).
5. 5–8 каталогов, вручную.
6. 6–10 технических статей на DEV/Hashnode за 90 дней с canonical на наш сайт (через API, с утверждением).

**Нужно проверить:** YouTube (стоимость времени владельца vs отдача), GitHub (что именно открывать), Reddit (только органично, если есть подходящее сообщество).

**Отложить:** Yandex, Telegram, расширения/приложения (Фаза 2+), Chrome/Microsoft/Google Play.

**Исключить:** X/Quora/Medium автоматизацию, массовые каталоги, платные ссылки, накрутки, автопосты в Reddit/HN, фейковые отзывы.

## 3. Контент-план (оригинальный, на реальных функциях)
- Страница каждого инструмента: что делает, как работает, ограничения, приватность, пошаговая инструкция со скриншотами, FAQ, сравнение с альтернативами (честное).
- Руководства: «How to compress a PDF under 1 MB without losing text», «How to translate a PDF to Arabic and keep the layout», «Translate scanned PDF: what works and what doesn't».
- Исследовательские материалы, которые дают естественные ссылки: сравнение качества перевода на реальных технических PDF (методика + данные), «Что остаётся в PDF после сжатия» и т.п.
- Контент создаётся с помощью AI, но **каждый материал проверяется человеком на фактическую точность и добавляет собственные тесты/данные**; массовая генерация шаблонных страниц запрещена.

## 4. Метрики по этапам
- 30 дн.: сайт проиндексирован (≥ 90% страниц в GSC «Indexed» ❓), 0 критических ошибок Core Web Vitals.
- 60 дн.: первые показы по long-tail; ≥ 1 внешняя ссылка естественного происхождения.
- 90 дн.: ≥ N кликов/день (цель определить после 30-дневной базы, ❓).
