Вывод: категория огромна, **доминируют 3–4 бренда**, и по головным запросам («merge pdf», «compress pdf», «pdf to word») новому домену соревноваться бессмысленно в первый год.

### Как получить реальные частотности бесплатно
1. Google Keyword Planner: аккаунт Google Ads можно создать без запуска рекламы (⚠ при отсутствии расходов диапазоны объёмов грубые). Не является покупкой рекламы, но требует заведения аккаунта — решение владельца.
2. Google Trends — относительная динамика и сравнение запросов, по странам.
3. Автодополнение Google, блок «Похожие запросы» и «Люди также ищут» — идеи для long-tail.
4. Bing Webmaster Tools → Keyword Research (бесплатно после подтверждения сайта) ⚠.
5. Search Console после запуска — единственный *реальный* источник по нашему сайту.
6. Ahrefs Webmaster Tools (бесплатно, только для своего сайта) ⚠; бесплатные генераторы ключей с лимитами.

## 3. Поисковые запросы: классы и ожидаемая роль

Без цифр. Классификация по характеру запроса:

| Класс | Примеры | Конкуренция | Коммерческая ценность | Роль |
|---|---|---|---|---|
| Головные | merge pdf, compress pdf, pdf to word, pdf editor | Экстремальная (iLovePDF, Smallpdf, Adobe, Sejda, PDF24) | Средняя | Не цель первого года |
| Специфичные модификаторы | compress pdf to 100kb, merge pdf without signup, compress pdf to 1mb | Высокая, но фрагментированная | Средняя | Долгий хвост, реалистичная цель |
| **Перевод** | translate pdf to arabic, translate pdf english to arabic keep formatting, translate scanned pdf, translate pdf with images | Умеренная ❓ (нужна проверка выдачи) | **Высокая** | **Главная ставка** |
| Узкие профессиональные | translate technical manual pdf, engineering drawing translation | Низкая ❓ | Высокая | Нишевый контент |
| Информационные | how to ... | Средняя | Низкая сама по себе | Вспомогательные статьи |

Идея пар «язык→язык» (программные страницы): ограничить 10–20 реально поддерживаемыми парами с уникальным контентом и демонстрацией. Масштабное создание тысяч страниц-шаблонов — риск «scaled content abuse»/thin content в политике Google. ✔ принцип; нужно проверять актуальные spam policies.

## 5. Реальные преимущества, которые мы можем предложить
1. **Приватность по построению:** простые операции выполняются в браузере — файл не покидает компьютер. Проверяемое заявление (открытый DevTools), дешёвое для нас (нет серверных затрат) и отличное для SEO-контента.
2. **Без регистрации, без водяных знаков, прозрачные лимиты.**
3. **Перевод PDF с сохранением вёрстки + корректный RTL (арабский)** — самый вероятный дифференциатор.
4. **Технические документы** (схемы, чертежи, таблицы): ваш инженерный опыт — основа реальной экспертизы (E-E-A-T) и тестового корпуса.
5. **Оригинальные инструкции и сравнения** на реальных кейсах.
