## Следствия решений D7 и D8 (для проектирования)
- Собственный сервер дома/в офисе = нет арендной платы, но: **доступность** (электричество, интернет, ИБП), **безопасность** (отделить от домашней сети, VLAN/отдельная машина, обновления), **публикация** через Cloudflare Tunnel без открытых портов ⚠ (условия использования Cloudflare проверить), внешний IP не светить.
- Статический сайт (Next.js SSG) можно держать на Cloudflare Pages, а на своём сервере — только API/БД/очередь/хранилище; тогда падение сервера не обрушивает SEO-страницы и клиентские инструменты.
- Резервные копии БД — на другой диск/ПК + зашифрованная копия вне дома.
- Воркеры на Windows: WSL2 + Docker Desktop с поддержкой NVIDIA CUDA (проверить версии драйвера ⚠); агент воркера — на Python (запуск как служба Windows через NSSM/Task Scheduler) ❓ уточнить при проектировании.
- Экономия: ≈ $6–10/мес по сравнению с VPS; бюджет в пределах $10–40/мес сохраняется (домен ≈ $1/мес + электричество).
