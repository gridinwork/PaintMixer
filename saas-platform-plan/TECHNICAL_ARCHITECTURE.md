# TECHNICAL_ARCHITECTURE.md — Техническая архитектура

Дата: 2026-10-12. Цель: минимальные постоянные расходы, безопасность, возможность использовать ваш NVIDIA GPU.

## 1. Главная идея: «клиент-first»
Простые операции (merge, split, rotate, delete, reorder, JPG↔PDF, PDF→images, часть compress, текст через PDF.js) выполняются **в браузере** (pdf-lib, PDF.js, WASM). Плюсы: стоимость серверов ≈ 0, файл не покидает компьютер (приватность — продающий довод), масштабируется бесплатно. Минусы: ограничения памяти браузера на очень больших файлах (поэтому серверный fallback), нельзя скрыть логику.
Сервер нужен только для: OCR, Word↔PDF (LibreOffice), качественное сжатие, перевод, AI-функции.

## 3. Размещение: сравнение

| Вариант | Расходы | Плюсы | Минусы | Вердикт |
|---|---|---|---|---|
| Полностью локально (ваш ПК/сервер с GPU + Cloudflare Tunnel) | ≈ электричество + интернет | Дешёвый GPU, полный контроль | Доступность (отключения, домашний IP), безопасность (вскрытие локальной сети), нужно проверить условия Cloudflare по ресурсам | Только для воркеров перевода |
| Полностью облако | VPS ≈ $5–20; GPU-облако дорого ❓ | Стабильность | GPU в облаке — главный расход | Для сайта/API/БД |
| **Гибрид (рекомендуется)** | VPS $6–15 + ваш GPU | Сайт и БД стабильны; тяжёлые задачи на вашем GPU через исходящее соединение воркера (pull-очередь) | Усложнение; нужен fallback при выключенном GPU | ✔ |

В гибриде GPU-воркер **сам подключается к очереди** (исходящее TLS), поэтому домашний ПК не нужно открывать в интернет. При выключенном воркере функция перевода показывает «в очереди»/временно недоступна.

## 4. Безопасность файлов

- HTTPS везде, HSTS, шифрование при передаче; файлы по случайным токенам, без публичных URL; доступ по подписанным ссылкам с TTL.
- Лимиты: размер (например 50–100 МБ ❓), число страниц, время CPU, RAM; отклонение зашифрованных/«бомб» (сверхсжатые потоки, рекурсивные объекты).
- Парсинг PDF — в **изолированных процессах**: непривилегированный пользователь, контейнер с `--network none`, read-only FS, seccomp, cgroup-лимиты, таймауты; LibreOffice — отдельный контейнер на каждую задачу (или пул с чисткой профиля).
- Антивирусная проверка (ClamAV) для загружаемых файлов на сервер ⚠ (дополнительный слой, не панацея); санитизация: не выполнять JavaScript внутри PDF, не следовать внешним ссылкам.
- Rate limiting (по IP/устройству), CAPTCHA для тяжёлых функций (Cloudflare Turnstile бесплатно ⚠).
- Секреты вне репозитория; бэкапы БД зашифрованы, ротация; файлы пользователей **не бэкапятся**.
- Логи без содержимого документов; отдельная политика хранения.

## 5. Конфиденциальность и юридическое
Privacy Policy, Terms, Cookie-политика, DPA-шаблон для бизнес-клиентов; явное описание: что обрабатывается в браузере, что — на сервере, сроки хранения (≤ 1 ч). GDPR/UK GDPR: законное основание — исполнение договора/согласие; права субъектов; при сервере в ЕС/США — уточнить передачу данных. Если перевод идёт через сторонний API (не рекомендуется на старте), необходимо раскрывать субпроцессора. Требуется консультация юриста перед запуском платных функций.

## 6. Масштабирование и стоимость
- Статический фронтенд + клиентские инструменты: ≈ $0 при росте трафика.
- Серверные задачи — единицы CPU-секунд; GPU — только перевод.
- Ориентир инфраструктуры: $10–40/мес до ~100k визитов (см. FINANCIAL_FORECAST).
